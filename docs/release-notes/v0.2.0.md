**Nexora is now Nexora.** Same app with a new name. Updating keeps your settings, data, add-ons and Nexora sign-in. The Start menu, Installed apps, Task Manager and the tray menu say Nexora, and the installer removes the old Nexora shortcut. The project now lives at [github.com/dasunjlk/Nexora](https://github.com/dasunjlk/Nexora) and [dasunjlk.github.io/Nexora](https://dasunjlk.github.io/Nexora/); the old links forward there.

**On a Mac, the app is Nexora.** Quit Nexora first (menu bar icon › Quit Nexora), because only one copy runs at a time. When Nexora first opens, it moves the old Nexora app to the Trash, where you can put it back if you need to.

**Pill, a fourth theme (new in 0.1.21).** Right-click the island, then **Theme › Pill**, or pick it in Settings. The island floats a little below the top of the screen as a black capsule with layouts of its own: the time and battery at rest, a **Status bar** idle look (the volume, the date and time, the battery), the line being sung while music plays, with bars and a glow in the album's colour, and a card with rounded corners when it opens. On a MacBook with a notch, the resting island stays beside the camera and the rest floats just below it. Classic stays the default.

**Install:** download `Nexora-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Nexora\nexora.exe`. Links to `Oyen-Nexora-Setup.exe` keep working: every release carries that file too.

**On a Mac:** open `Nexora-Mac.dmg` and drag Nexora into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading from Nexora 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Nexora`; the folders keep their old names).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
