Nexora is now **Nexora**, part of the Nova family, with a new icon and a new look for Setup.

**Install:** download `Nexora-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Nexora\nexora.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Nexora`). The Start menu entry is now called Nexora.

**Also new:** synced lyrics for Apple Music, whose artist field ("Artist — Album") used to make every lookup miss.

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
