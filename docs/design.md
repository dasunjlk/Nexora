# Nexora — design doc

## 1. Brand

| Token | Value | Notes |
|---|---|---|
| Product name | **Nexora** | everywhere user-visible |
| Mascot | **Nova** | the app's cat, drawn procedurally from vectors (`nexora_core::nova`), recoloured from the upstream mascot to Nexora's palette |
| Accent (primary) | `#7C5CFF` violet | replaces the upstream orange `#F0892E` in UI accents, logo, installers, website — and is Nova's fur and the Nova theme's accent, so one violet reads on both the porcelain theme and black |
| Accent (deep) | `#5B3FD6` indigo | Nova's ear fold; pressed states |
| Tile (logo ground) | `#8B6CFF` → `#6E4BE8` gradient | the logo tile; `#6E4BE8` is the theme accent's deep end |
| Ink | `#171717` | dark surfaces, text on light |
| Theme names | Classic, **Nova**, Glass, Pill, Diorama | "Nova" replaces the upstream mascot theme |
| Typeface | Outfit (OFL) | unchanged; `server/OFL-Outfit.txt` carries the licence |
| Logo | `docs/brand/nexora-logo.svg` (+ `-512.png`, `-white.svg` mark) | generated by `tools/make_brand.py`; a rounded violet tile with the black island playing music at its top edge and the white Nova below |
| Installer art | `installer/art/*` | regenerated by `tools/make_brand.py` in Nexora colours |

The mascot's orange (`#F0892E`, fold `#C9581A`) is replaced by the violet
family everywhere it is drawn or encoded (`look` palettes, brand generator,
phone page). The mascot keeps its geometry so the port stays faithful; only
the character's name and colour change.

## 2. System design (summary)

```
 services (own threads / COM callbacks)          UI thread (owns everything below)
 ─────────────────────────────────────          ─────────────────────────────────
 media (GSMTC)      ─┐                           App ── AppState (state.rs)
 lyrics (LRCLIB)    ─┤  EventSink.send(AppEvent)  │      ├─ pages/*      draw via Ui, push Commands
 audio (volume)     ─┼──► mpsc + PostMessage ───► │      ├─ activities  collapsed pill content
 bluetooth          ─┤     (WM_APP_EVENT)         │      └─ island       spring-animated outline
 imaging (thumbs)   ─┤                            │
 phone drop (LAN)   ─┘ on demand                  │
 frame clock thread ── WM_APP_FRAME (vblank, only while animating)
```

- **Rendering** — Direct2D on a Direct3D 11 device (hardware, else WARP) into
  a premultiplied flip-model swap chain shown by DirectComposition; software
  DIB fallback. All coordinates are DIPs; the window is a fixed-size layered
  window sized for the largest island so morphs never move it.
- **Frame clock** — a thread waits on the display's vblank and posts
  `WM_APP_FRAME`; timestamps phase-locked to the refresh. No frames at rest.
- **Window** — `WS_EX_LAYERED | WS_EX_TOPMOST | WS_EX_TOOLWINDOW |
  WS_EX_NOACTIVATE`; never takes focus except in text fields.
- **Contracts** — pages are `height(st)` + `draw(ui, st, area)`; services
  `start(sink) -> …` and talk only through `AppEvent`s; pages request through
  `Command`s; `app.rs` maps both onto `AppState`.
- **Crates** — `nexora-core` (pure logic + models, no OS calls),
  `nexora-usage` (AI-plan readers, pure, built for size), `nexora-diorama`
  (Diorama theme picture, pure), `nexora` (the apps: Windows `src/`, macOS
  `src/mac/`).
- **Storage** — settings/data JSON under `%APPDATA%\Nexora`; cache/log under
  `%LOCALAPPDATA%\Nexora`; sealed secrets per-file (DPAPI on Windows,
  owner-only files on macOS); `NEXORA_HOME` overrides both (self-test).

Full architecture (threads, pages, services, the Mac app): `ARCHITECTURE.md`
in the repo root.

## 3. UX notes

- The island rests as a small pill; hovering lifts it, dwell opens the pages.
- Tabs: Music, Today, Shelf, Tasks, Focus, AI, Nexora, then add-on tabs and
  the "+" add-on picker; scroll over the top edge switches pages.
- Right-click menu and the tray icon carry the quick settings; a separate
  borderless Settings window ("Advanced settings") holds everything, shared
  between Windows and macOS drawing code.
- Meeting notes (Notes tab): one click records; Nova's head moves with the
  voices; two level bars (mic, PC sound); Stop hands the audio to the server
  and the notes arrive as Markdown. See
  [features/meeting-notes.md](features/meeting-notes.md).
- Everything is English-first and works without an account.
